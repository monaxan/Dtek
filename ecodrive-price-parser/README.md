# EcoDrive price parser

Парсер ежедневно открывает карточки EcoDrive через Chromium/Playwright и обновляет Google Sheet.

## Что обновляется

Исходная таблица:

- A — название
- B — ссылка EcoDrive
- C — цена EcoDrive
- D — наличие
- F — ваш SKU
- G/H — не изменяются
- I — последняя проверка
- J — статус парсера
- K — артикул EcoDrive
- L — изменение цены

При ошибке парсинга цена и наличие **не обнуляются**. В J записывается ошибка, старая цена остаётся в C.

Дополнительно создаётся вкладка `История цен`.

## 1. Заменить Apps Script

Откройте нужную Google Таблицу:

`Расширения -> Apps Script`

Замените текущий код содержимым:

`apps-script/Code.gs`

Сохраните и один раз вручную запустите:

`setupEcoDriveBridge`

Скрипт:

- запомнит ID таблицы;
- запомнит текущую вкладку как источник;
- создаст колонки I-L;
- создаст вкладку `История цен`;
- создаст секретный токен.

В журнале выполнения появится `APPS_SCRIPT_TOKEN`.

Если токен нужно посмотреть повторно, запустите:

`showEcoDriveBridgeConfig`

## 2. Развернуть Apps Script как Web App

В Apps Script:

`Развернуть -> Новое развертывание -> Веб-приложение`

Параметры:

- Execute as / Выполнять от имени: **Me / Я**
- Who has access / У кого есть доступ: **Anyone / Все**

После развертывания скопируйте URL, который заканчивается на `/exec`.

## 3. Добавить GitHub Secrets

Repository -> Settings -> Secrets and variables -> Actions -> New repository secret

Обязательные:

- `APPS_SCRIPT_WEBAPP_URL` — URL `/exec` из Apps Script
- `APPS_SCRIPT_TOKEN` — токен из `setupEcoDriveBridge`

Необязательные, только если EcoDrive начнёт блокировать IP GitHub Actions:

- `PROXY_SERVER` — например `http://host:port`
- `PROXY_USERNAME`
- `PROXY_PASSWORD`

Без прокси эти три секрета можно не создавать.

## 4. Первый тест

GitHub -> Actions -> `EcoDrive Price Parser` -> `Run workflow`.

После завершения проверьте:

- C — актуальная цена;
- D — наличие;
- I — время проверки;
- J — `OK`;
- K — SKU EcoDrive;
- L — изменение цены.

Если отдельная карточка не распарсилась, в artifact `ecodrive-parser-debug` будет скрин страницы.

## Автоматический запуск

Workflow запускается раз в сутки по cron:

```yaml
37 2 * * *
```

GitHub cron использует UTC. Точное время запуска может немного сдвигаться, но период — ежедневно.

## Защита от ошибок

- 3 попытки открыть каждую карточку;
- последовательный обход без агрессивного параллелизма;
- случайная пауза между товарами;
- прогрев главной страницы EcoDrive перед обходом;
- JSON-LD -> meta -> DOM fallback для определения цены;
- старая цена не заменяется на `0` при ошибке;
- URL сверяется перед записью в строку;
- изменения цены и наличия пишутся в историю.
